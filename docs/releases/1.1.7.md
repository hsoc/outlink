# Outlink 1.1.7

Stable release. App version **1.1.7**, Android version code **22**, iOS build number **22**.

## Changes since 1.1.5

- Update the app icon, in-app logo and launch screen with the supplied blue
  chat-bubble artwork, preserving its original “bitchat” lettering. Use a white
  launch background and padding for Android adaptive launcher masks. Remove the
  retired custom monochrome icon; themed presentation depends on the launcher.
- Simplify the Android and iOS Bluetooth adapters to Bitchat only. Remove the
  retired protocol's UUIDs, profile exchange, extra framing and reassembly, and
  unused native APIs. Keep Bitchat Bluetooth mesh, MTU-aware protocol fragmentation,
  connection generations, notifications and background connectivity.
- Remove the unused navigation helper and Electron-only license snapshot. Preserve
  required image/build-tool notices and integrity checks under a platform-neutral
  directory.

Channel identity rotation and its private-conversation migration extension remain
included. Cashu transfers, contacts, blocking and donations remain available.
The cancelled 1.1.6 release was not published; this release includes its artwork
changes together with the subsequent Bluetooth cleanup.

## Validation

The cleanup passed 328 app tests, TypeScript, lint, storage/configuration and
license checks, both mobile bundle exports, Android native compilation/unit tests,
and an unsigned iOS simulator build. Physical-device/radio testing of these changes
has not been performed. Simulator compilation does not prove radio interoperability.
See the [native validation run](https://github.com/hsoc/outlink/actions/runs/41309513461).

## Downloads and updating

- **Outlink-android.apk**: signed Android installer for direct installation.
- **Outlink-android.aab**: signed Google Play Console bundle; not directly installable.
- **SHA256SUMS.txt**: checksums for both Android files.

Install over the previous signed Outlink app to retain identity, contacts and
unexpired data. The application ID remains `io.github.hsoc.outlink`. A new native
build is required for the Bluetooth interface changes. No iOS IPA is included;
iOS version/build metadata and native source are updated for future builds.
