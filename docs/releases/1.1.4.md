# Outlink 1.1.4

Stable release. App version **1.1.4**, Android version code **19**, iOS build number **19**.

## Changes since 1.1.3

- Show `[HH:mm:ss]` beside the sender nickname in Nearby, Location public/private
  conversations and Bluetooth groups, using 24-hour local device time.
- Display the original message time for older loaded messages too, rather than
  the time you joined the channel. Six-hour chat retention remains unchanged.
- Improve Bitchat action-message compatibility: hug, slap and `/me` actions use
  Bitchat's ordinary `* ... *` text in Nearby and Location public/private chat.
  Older `/me` messages display as actions while Copy preserves their original text.

Includes the merged action-message fix and timestamp update. Automated checks
verify these changes; new physical-device validation has not been recorded.

## Downloads and updating

- **Outlink-android.apk**: signed Android installer for direct installation.
- **Outlink-android.aab**: signed Google Play Console bundle; not directly installable.
- **SHA256SUMS.txt**: checksums for both Android files.

Install over the previous signed Outlink app to retain identity, contacts and
unexpired data. The application ID remains `io.github.hsoc.outlink`. No iOS IPA is
included; its version/build metadata is updated for future builds.

See [message actions](https://github.com/hsoc/outlink/blob/v1.1.4/docs/protocols/message-actions.md)
and [conversation display](https://github.com/hsoc/outlink/blob/v1.1.4/docs/DESIGN.md).
