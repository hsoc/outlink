# Outlink 1.1.9

- Send images and recorded voice notes in Public Mesh and Nearby DMs. Recipients choose whether to accept each attachment.
- Use opt-in live listening and hold-to-talk in Nearby. DM voice and attachments are encrypted with Noise.
- Find image, recording, listening, and push-to-talk icons beside Send.
- Nearby DMs have separate history paging and persistent unread counts.
- Security updates protect private delivery routing, limit unsolicited thread records, pin the relay directory, and resume interrupted identity erasure.

Android version code and iOS build number are 24. Physical-device media and live voice interoperability have not been verified.
