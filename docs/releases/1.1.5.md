# Outlink 1.1.5

Stable release. App version **1.1.5**, Android version code **20**, iOS build number **20**.

## Changes since 1.1.4

- Add an optional **Support Outlink** section in Settings with a one-tap button
  opening the developer's Coinos donation page and a copyable reusable Lightning
  Address: `hsoc@coinos.io`.
- Document Lightning donations in the README and a dedicated donation guide;
  add the GitHub funding link.
- Keep Bitcoin payments entirely in external wallets/services. Donations are
  optional, do not unlock features, and require internet access.

Automated checks validate the source and mobile exports. External Coinos
payment completion and new physical-device wallet handoff have not been
independently verified.

## Downloads and updating

- **Outlink-android.apk**: signed Android installer for direct installation.
- **Outlink-android.aab**: signed Google Play Console bundle; not directly installable.
- **SHA256SUMS.txt**: checksums for both Android files.

Install over the previous signed Outlink app to retain identity, contacts and
unexpired data. The application ID remains `io.github.hsoc.outlink`. No iOS IPA
is included; its version/build metadata is updated for future builds.

See [donation instructions](https://github.com/hsoc/outlink/blob/v1.1.5/docs/DONATIONS.md).
