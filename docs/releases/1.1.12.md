# Outlink 1.1.12

- Keeps joined Location channels and enabled private messages active in the Android background independently of Nearby, when background connectivity is enabled.
- Shares one ongoing connectivity notification and Stop control across Nearby and Location channels.
- Fixes opening received images and voice notes, and preserves attachment offers for retry if a preview cannot be saved.
- Adds microphone-level bars and elapsed time for voice notes, plus animated activity bars and elapsed time for push-to-talk.
- Preserves text drafts and respects reduced-motion settings.
- Makes operation errors dismissible and keeps transport error notices in their corresponding Nearby or Location view.

Android version code and iOS build number are 27. This release includes the changes prepared for the canceled v1.1.11 release. Physical-device verification of these changes remains outstanding. Android battery restrictions can still interrupt background connectivity.
