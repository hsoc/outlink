# Outlink 1.1.6

Stable release. App version **1.1.6**, Android version code **21**, iOS build number **21**.

## Changes since 1.1.5

- Use the maintainer-supplied blue chat-bubble artwork for the app icon and in-app
  logo, preserving the original “bitchat” lettering exactly as requested.
- Show the same artwork on a white launch screen on Android and iOS.
- Add padding for Android adaptive launcher masks and remove the retired custom
  monochrome icon. Themed-icon presentation depends on the launcher.

The original supplied PNG is retained unchanged; platform assets are resized
copies. Android and iOS native project generation and mobile configuration checks
passed. New physical-device validation of these artwork changes has not been recorded.

## Downloads and updating

- **Outlink-android.apk**: signed Android installer for direct installation.
- **Outlink-android.aab**: signed Google Play Console bundle; not directly installable.
- **SHA256SUMS.txt**: checksums for both Android files.

Install over the previous signed Outlink app to retain identity, contacts and
unexpired data. The app remains named Outlink with application ID
`io.github.hsoc.outlink`. No iOS IPA is included; its version/build metadata and
artwork configuration are ready for future builds.
