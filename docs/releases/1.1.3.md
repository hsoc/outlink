# Outlink 1.1.3

Stable release. App version **1.1.3**, Android version code **18**, iOS build number **18**.

## Changes since 1.1.2

- Silence system alerts for the conversation you are viewing in the foreground,
  including Public Mesh and Location-channel private conversations. Alerts for
  other conversations still follow your settings.
- Show red unread dots on Nearby, Location channels, public/area selectors, DM
  shortcuts and Bluetooth groups. Opening the conversation clears its indicator.
- Add **Notify for all Nearby messages in background**. When enabled alongside
  running background connectivity on Android, receive alerts for ordinary Public
  Mesh messages, Nearby DMs and joined Bluetooth group messages. Notification
  previews keep names, message text and group/area details private.
- Keep the separate mention and private-message notification preferences for use
  outside the new background mode. The new option defaults off and does not join
  a mesh or enable background connectivity automatically.
- Move Appearance below the background connectivity and notification controls.

Public/group unread dots track new arrivals during the running session and expire
with six-hour history retention; they are not restored on a cold launch. DM unread
status retains its existing persisted behavior. Notification permissions, Android
background restrictions and bounded burst queues still apply. No remote push or
wake-up after force-stop is added. These notification changes passed automated
checks; new physical-device notification validation has not been recorded.

## Downloads and updating

- **Outlink-android.apk**: signed Android installer for direct installation.
- **Outlink-android.aab**: signed Google Play Console bundle; not directly installable.
- **SHA256SUMS.txt**: checksums for both Android files.

Install over the previous signed Outlink app to retain identity, contacts and
unexpired data. The application ID remains `io.github.hsoc.outlink`. No iOS IPA
is included; its version/build metadata is updated for future builds.

See [notification settings and behavior](https://github.com/hsoc/outlink/blob/v1.1.3/docs/protocols/mentions.md)
and [background connectivity](https://github.com/hsoc/outlink/blob/v1.1.3/docs/protocols/background-connectivity.md).
