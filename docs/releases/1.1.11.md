# Outlink 1.1.11

- Fixes opening received images and voice notes after accepting an attachment.
- Preserves received attachments for retry if creating a preview fails.
- Adds microphone-level bars and elapsed time while recording voice notes.
- Adds animated activity bars and elapsed time while holding push-to-talk.
- Preserves text drafts and respects reduced-motion settings.

Android version code and iOS build number are 26. These changes have not been verified on a physical device.
