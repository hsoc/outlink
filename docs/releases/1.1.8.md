# Outlink 1.1.8

Stable release. App version **1.1.8**, Android version code **23**, iOS build number **23**.

## Changes since 1.1.7

- Enable Android R8 code optimization, shrinking and class/member obfuscation,
  plus optimized resource shrinking for release builds.
- Retain the framework's JNI/reflection rules and Expo's bundled-asset keep rules
  for app functionality, images and license notices.
- Verify actual optimizer output and record DEX metrics. Preserve mapping files
  in build artifacts for crash debugging.
- Require the signed release APK to pass an Android emulator startup check before
  publishing a release.

The validation build reduced uncompressed DEX code from 52.9 MB to 12.0 MB
(77.3%) and the universal APK from 141.2 MB to 127.3 MB (9.9%), compared with
published v1.1.7. Per-build figures are recorded in the optimization report.
All four Android architectures remain included.

These changes optimize Android Java/Kotlin code. JavaScript remains compiled with
Hermes; this does not change encryption or the messaging protocols. Channel identity
rotation and its private-conversation migration extension remain included.

## Validation

The optimization validation passed release checks and an API 36 x86_64 emulator
startup check using the actual signed APK. It rendered the Nearby/Location controls
and remained running without an app crash. Physical Bluetooth, background-radio
and private-message validation on the optimized APK remains outstanding; startup
checks do not establish device interoperability.

See [Android optimization and measured results](https://github.com/hsoc/outlink/blob/v1.1.8/docs/security/android-optimization.md).

## Downloads and updating

- **Outlink-android.apk**: signed Android installer for direct installation.
- **Outlink-android.aab**: signed Google Play Console bundle; not directly installable.
- **SHA256SUMS.txt**: checksums for both Android files.

Install over the previous signed Outlink app to retain identity, contacts and
unexpired data. The application ID remains `io.github.hsoc.outlink`. No iOS IPA
is included; its version/build metadata is updated for future builds.

Crash mappings are retained for 90 days in the run's **android-r8-reports** artifact;
archive them for long-term debugging. They are not separate public release downloads.
