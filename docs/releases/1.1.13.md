# Outlink 1.1.13

- Adds Copy, Message user, Hug, Slap and Block actions to private Bluetooth group messages.
- Shows matching unread DM shortcuts/counts beside Public Mesh and the location area, plus unread dots on Nearby Contacts and contact cards.
- Returns from Nearby and Location DMs without disconnecting the public session.
- Corrects Location DM block identities and preserves blocks across proven identity rotation.
- Updates Android system-bar handling for Android 15 and newer while retaining older Android compatibility.
- Updates Material components to 1.14.0 for native bottom-sheet compatibility fixes.
- Upgrades the Android build toolchain to AGP 9.0.1 and Kotlin 2.2.10, retaining R8 optimization, obfuscation and resource shrinking.

Android version code and iOS build number are 28. Native dependency patches require React Native and Hermes source builds, so Android builds take longer. Physical-device verification and a new Google Play warning scan remain outstanding. Memory and runtime performance improvements have not been measured.
