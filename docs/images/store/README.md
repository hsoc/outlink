# Store screenshots

Recapture screenshots from verified Outlink builds before store submission.
The previous image set was removed because it displayed the upstream title.

Place current Android screenshots in
`fastlane/metadata/android/en-US/images/phoneScreenshots/`, named `1.png`,
`2.png`, and so on. Both F-Droid and Zapstore read that Fastlane directory.
Capture the conversation list, nearby devices, and light and dark conversations.
Do not describe screenshots as current until the files have been supplied.
