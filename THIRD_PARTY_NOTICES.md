# Third-party notices

Outlink's application code is MIT licensed; original copyright notices in LICENSE
remain intact. Dependencies retain their own licenses. Original notice snapshots
are preserved under licenses/third-party and assets/licenses for provenance.

The current mobile dependency closure and its original texts are recorded in
licenses/third-party/common/npm-inventory.json and npm-notices.txt. Conservative
mobile native framework notices are retained in common/mobile-native.txt. A
historical source snapshot is not a claim that every component still ships.

The mobile app bundles the generated notice catalog and referenced text assets,
available offline from Settings. Solar Icons retain their CC-BY attribution and
license in licenses/third-party/common. No upstream Bitchat application source
was incorporated; interoperable protocol fields and independently generated
cryptographic test vectors do not change the application license.

Regenerate after dependency changes with npm run licenses:refresh and verify with
npm run licenses:check. Do not remove copyright/license texts when pruning unused
application features.
